### Создание иконок на рабочем столе

1. Открой терминал
2. Перейди в директорию ~/Desktop
3. Создай файл ярлыка (с помощью nano/vim) с расширением .desktop
4. Открой его и запиши туда параметры:

```ini
[Desktop Entry]
Type=Application
Name=Имя приложения
Exec=/путь/к/программе_или_команда
Icon=/путь/к/иконке.png
Terminal=false
```

|Команда|Значение|
|:---|:---|
|[Desktop Entry]| Название секции (логического блока)|
| Type=Application | Тип ярлыка. Указывает что ярлык запускает программу <br> (а не ссылку на сайт или какую-нибудь папку)|
| Name=Имя приложения | Название приложения|
| Exec=/путь/к/файлу | Путь к тому, что мы будем исполнять (код или команда)|
| Icon=/путь/к/иконке.png | Путь к иконке ярлыка|
| Terminal=false | Запуск в терминале. True - запускаем программу в терминале,<br> False - ставим когда хотим запустить игру или приложение(не консольное)|


## Установка Arch Linux

### 1. Выбор языка 
Для начала нужно поставить раскладку клавиатуры. Для выбора языка используется команда `loadkeys ru` (на месте "ru" вы ставите свой язык.

### 2. Проверка режима загрузки(UEFI/Legacy)
Нам нужно узнать в каком режиме загрузилась наша система: UEFI или Legacy (BIOS).<br>
Для этого нам нужно ввести команду: `ls /sys/firmware/efi/efivars`. Если есть вывод директории, то мы в UEFI. Если его нету, мы в Legacy.

### 3. Проверка соединения
Теперь мы проверяем доступное соединение командрой `ip link`. Эта команда показывает доступные проводные и беспроводные сетевые интерфейсы. Это может быть WiFi или Ethernet.

- Если мы подключены к Ethernet (по кабелю), то ничего делать не нужно.
- Если хочешь подключиться по WiFi (беспроводному интернету), то тогда введи команду: `iwctl --passphrase "YourPassword" station wlan0 connect "YourNetwork"`. (В данном случае `wlan0` это имя твоего интерфейса из команды `ip link`)

### 4. Проверка качества соединения
Чтобы проверить качество соединения, пишешь команду: `ping -c 3 archlinux.org`. Мы пингуем сайт `archlinux.org`. То есть мы отправляем на него пакеты с даннымы и смотрим, дошли ли они все и не потерялись ли они в пути.
Если в выводе будет строчка `0% packet loss`, то это значит, что все пакеты с данными дошли без потерь и интернет работает стабильно.

### 5. Синхронизация системного времени и даты
Теперь нужно синхронизировать дату и время. Чтобы это сделать, пиши команду: `timedatectl set-ntp true`. Она говорит системе включить службу синхронизации времени, чтобы подстроить его.

### 6. Выбор зеркал 
Теперь нужно выбрать зеркала для скачивания программ из репозиториев. От этого зависит скорость загрузки программ, обновлений, и всего того, что вы будете скачивать.<br>
Пиши команду: `reflector --country US --latest 20 --protocol https --sort rate --save /etc/pacman.d/mirrorlist`, она автоматически выберет лучшие сервера (зеркала) для будущего быстрого скачивания. 

### 7. Вывод списка дисков
Теперь, независимо от режима загрузки UEFI или Legacy, пиши команду `lsblk` для показа информации о дисках. Эта информация понадобится нам для дальнейшей разметки.

### 8. Разметка диска
Для разметки диска в режиме загрузки UEFI нужно использовать команду `gdisk /dev/sda`, где `sda` - это твой диск. То есть нужно вписать название твоего диска в этом месте: `sda`. В итоге получится команда: `gdisk /dev/твой диск`.

### 9. Форматирование раздела EFI
Чтобы отфармотировать раздел, нам нужно написать команду: `mkfs.fat -F32 /dev/sda1`. Она форматирует раздел (удаляет все данные) и переводит его в формат FAT32. Это нужно для дальнейшей установки системы в UEFI режиме.

### 10. Раздел подкачки SWAP
Также нужно создать раздел подкачки. Он нужен для того, чтобы при полной загрузке основной ОЗУ программа не вылетала. Раздел подкачки SWAP медленнее, чем обычная оперативная память, но он предотвращает внезапные вылеты программ и сбои при работе.<br>Чтобы его сделать пиши команду: `mkswap /dev/sda2`.

Теперь активируй раздел подкачки, который мы сейчас создали с помощью команды: `swapon /dev/sda2`.
<br>Без этого он работать не будет.

### 11. Форматирование корневого раздела
Форматирование корневого раздела будет в файловую систему ext4. Эта файловая система самая стабильная, на ней будут лежать все файлы системы. Делается это командой: `mkfs.ext4 /dev/sda3`.
Вместо `sda3` пишем название своего диска, как в шаге номер 8 по той же логике.

### 12. Монтирование корневого раздела
Настало время монтировать раздел нашего диска. Это нужно, чтобы система понимала, куда записывать файлы. Т.к. мы сейчас отформатировали корневой раздел, то будем подключать именно его.
Для этого пишем команду: mount `mount /dev/sda3 /mnt`

### 13. Создание загрузочкной директории
Загрузочкая директория (или точка монтирования) создаётся командрой: `mkdir -p /mnt/boot`. В эту папку мы примонтируем EFI.

### 14. Монтирование загрузочного раздела (EFI)
Монтирование загрузочного раздела нужно для того, чтобы связать наш первый раздел `/dev/sda1` из шага 8 с загрузочной директорией `/mnt/boot`, которую мы создали на прошлом 13 шаге.
Для этого введи команду: `mount /dev/sda1 /mnt/boot`

### 15. Установка базовой системы
Теперь устанавливаем базовую систему этой командой:
<br>`pacstrap -K /mnt base linux linux-firmware base-devel nano networkmanager sudo`
<br>Она установит всё необходимое для функционирования системы.

### 16. Генерация /etc/fstab
Эта команда нужна для того, чтобы система после перезагрузки знала, какие диски нужно автоматически подключать.
<br>`genfstab -U /mnt >> /mnt/etc/fstab`.
Команда автоматически найдет все наши подключенные разделы (EFI, SWAP и корень), найдет их уникальные ID-номера (UUID) и запишет всю эту информацию в системный файл настроек "fstab".

### 17. Вход в новую систему
Пишем команду для захода в новую систему: `arch-chroot /mnt`

### 18. Временная зона
Создаём символическую ссылку для того чтобы в сисеме коррекно отображалось время: `ln -sf /usr/share/zoneinfo/America/New_York /etc/localtime`

### 19. Запись времени 
Записываем время в материнкскую плату: `hwclock --systohc`

### 20. Региональные настройки
Открываем конфигурационный файл `nano /etc/locale.gen`
