# Гайд на установку и запуск Nginx

## Установка

1. Обновляешь списки пакетов: `sudo apt update`
2. Устанавливаешь Nginx: `sudo apt install nginx`
3. Проверяешь статус службы: `sudo systemctl status nginx`
4. Закидываешь в автозагрузку: `sudo systemctl enable --now nginx `

## Подключение

1. Смотришь свой IP-адрес: `ip a`
2. Пишешь в браузере: `http://твой IP-адрес` без слеша

## Дополнительные возможности

### Имя вместо IP-адреса(Локально)
Можно поставить вместо IP-адреса, по которому ты ищещь сайт, любое другое название.
<br>Для этого пишешь команду: `sudo nano /etc/nginx/sites-available/default`
<br>Ищешь в файле строчку `server_name` и меняешь её на своё имя. Далее перезагружаешь службу: `sudo systemctl reload nginx`, чтобы применились изменения.

### Редактирование кода сайта
По  умолчанию Nginx показывает свой приветсвенный текст при подключении, но его можно поменять на код своего сайта.
Для добавления своего кода сайта нам нужно перейти в место, куда Nginx обращается, чтобы взять код.
<br>Переходим по пути `cd /var/www/html`, затем пишем команду `ls` и видим, что там по умолчанию лежит файл `index.nginx-debian.html`. Nginx держит в приоритете файл с таким названием, поэтому первым будет смотреть именно его. То есть если бы было 2 файла с расширением `.html`, то он бы открыл именно `index.nginx-debian.html`.
<br>Nginx имеет приоритет на эти названия:
<br>- `index`
<br>- `index.html`
<br>- `index.htm`
<br>- `index.nginx-debian.html`
<br>Поэтому мы можем удалить файл по умолчанию и вставить туда свои, например `.html` и `.css`.
